ProPhoto Editor

Version 1.5.4

A browser-based Photoshop clone built with HTML5 Canvas, CSS3, and Vanilla JavaScript.

About This Project

ProPhoto Editor brings professional-grade image editing capabilities to the web. Inspired by Adobe Photoshop, this application provides a comprehensive set of drawing tools, filters, and layer management features — all running entirely in your browser with zero dependencies.

New in v1.5.3: Shortcut keys shown in all tool tooltips. Export formats expanded to PNG, JPEG, WebP, and BMP. Fixed inline text editor positioning. Shape tool tooltips cleaned up.

Creator

Kyros Koh
Full-stack developer passionate about creating powerful web applications.

Features

✓ 15 Professional drawing, shape & selection tools
✓ Multi-layer support with opacity control
✓ 7 Image filters and effects
✓ Undo/Redo system (20+ steps)
✓ Project save/load (.prophoto format)
✓ Auto-save session state to localStorage
✓ Unsaved changes indicator
✓ Export to PNG/JPEG
✓ Mobile touch support
✓ Completely free and open-source
